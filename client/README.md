# client

This directory is a stub for optional frontend/web development (React, TypeScript, Vite, Electron, etc.).

**Not all projects require frontend work.** If this project does not have a frontend, this folder can be left empty or removed.

## When to use this

If your project needs a frontend, place all web/UI source here:

- React + TypeScript + Vite apps
- Electron renderer and main process code
- Any other browser or desktop UI

## Getting started

Install Node.js dependencies:

```powershell
.\bin\setup\get-npm.ps1
```

Then follow the setup instructions for your chosen framework.
