## Repository Overview

This is a **Python package template** for creating Python 3.11+ packages with modern tooling (`uv`, `ruff`, `ty`, `pytest`). It also supports frontend development with React + TypeScript + Vite and Electron.

## Template State

Check whether this repo has been initialized:

- **No `pyproject.toml`** → still a template. Guide the user to run `bin/setup/setup-project.ps1 -Name "project-name"`. They may need to run `bin/setup/get-uv.ps1` first.
- **`pyproject.toml` exists** → initialized project. Treat as a normal Python package.

## Key Files

- **`version.toml`** — single source of truth for version (major/minor/patch integers)
- **`VERSION`** — auto-generated by `python scripts/version.py`, do not edit
- **`ruff.toml`** / **`ty.toml`** / **`uv.toml`** — tooling configuration
- **`.agents/skills/`** — domain-specific coding standards and workflows

## Style Guides

Consult the relevant skill file before making domain changes:

- `.agents/skills/bumpversion/SKILL.md` — version bump and changelog workflow

## VCS Safety

Always require explicit user confirmation before executing any of the following version control commands. These commands must never be auto-approved:

- `git push` (any variant, including `--force`)
- `git commit` (any variant)
- `gh pr merge` (any variant)
